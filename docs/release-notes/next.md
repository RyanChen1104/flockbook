## What's New in vX.Y.Z

One short line: what this release is about.

### ✨ New
- Remote herdr: Flockbook can show the agents of a herdr that runs on another machine over ssh. Conversations, the reply field, pictures and attached files, the terminal, the git branch, the Claude Code question hook and the status line work on the host. Attached files and pictures are copied to the host first.
- Settings > General > Machine: choose which machine the window shows (this Mac, or a host over ssh). The switch takes effect after a relaunch.
