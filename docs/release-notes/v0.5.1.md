## What's New in v0.5.1

A bug-fix release: long Claude Code permission prompts no longer break the window.

### 🐛 Bug Fixes

- A Claude Code permission prompt with a long command no longer breaks the window. Before, a long command (for example a many-line heredoc) could make the window very tall: the tabs moved off the screen, and the conversation and the reply field disappeared. Now the tabs, the conversation and the reply field stay in place, and the command scrolls inside the card.
- With Reduce Transparency on, the tab island is exactly as tall as the + and terminal buttons beside it, and clicks on its edge reach the tabs.
