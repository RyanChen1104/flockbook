## What's New in v0.6.1

Fixes for tall permission prompts, the phone Screen view, and scrolling through earlier messages.

### 🐛 Bug Fixes

- A permission prompt taller than the terminal no longer gets a line of its command as the card's title. The card says the command is too long to show and to read it in the terminal; Allow and Deny still answer that prompt.
- On the phone and iPad, a Screen you open stays open while the agent works, and an opened tool chip stays open while its command runs. Before, the next update closed them.
- Scrolling up through earlier messages keeps your place while older messages load, also when a view between the message and the window moves during layout.
- Showing or hiding the sidebar keeps the window's sidebar state in step with the slide animation.
